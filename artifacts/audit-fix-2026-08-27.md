## 二、关键改动与代码铁证

### C1 — 上传链路统一到 EffectiveDataset 边界
`app/api/brain/table/upload/route.ts`：`mergeSheets` 返回 `SheetInfo`，调用 `buildEffectiveDataset(merged, { headerIdx: 0 })` + `profileEffectiveDataset(...)`；结果新增 `detectedHeaderRow / effectiveRowCount / effectiveColumnCount / excludedRows / excludedColumns / qualityIssues`（向后兼容）。修复前此处只走 `cleanSheet`+`profileTable`，T1-A/T1-C 裁剪与 T1-D1 推荐从未触达生产。

### C2 — SQLite 自举补表
`lib/db/index.ts`（`:110` 前插入，先于首个 FK 子表）：
```sql
create table if not exists users (id text primary key, email text not null unique, password_hash text, created_at integer not null);
create table if not exists projects (id text primary key, user_id text not null, ..., foreign key (user_id) references users(id) on delete cascade);
create table if not exists agent_settings (user_id text not null, role text not null, ..., primary key (user_id, role), foreign key (user_id) references users(id) on delete cascade);
```
实跑验证：better-sqlite3 全新 DB + `foreign_keys=ON` 自举成功，users/projects/agent_settings 落库，首个 FK 表 `brain_ima_sync_log` 建表 + 插入通过。

### H1 — 评论 IDOR 归属校验
`lib/brain-db.ts`：`listBrainTaskComments` / `listBrainTaskTimeline` 前新增 `const task = await getBrainTaskById(userId, taskId); if (!task) return [];`（同源头隐患一并闭环）。

### H7/H8 — 保文本规则
`lib/table/cleaner.ts`（`cleanCellValue`，NULL 检查之后、数字解析之前）：
```ts
if (/^0\d+$/.test(s) || /^\d{16,}$/.test(s)) return s;  // 前导零码 / ≥16位大整数保文本
```

### H9 — 纯 Excel 序列号列归一化
`lib/table/cleaner.ts`（`inferColumnTypeDetailed`）：新增 `isExcelSerial`（窗口 20000–70000 且可解析为日期），dateRatio 计数列含序列号；命中时在 reasons 标注「检测到 Excel 序列号日期（如 45320 → 2024-01-29）」。`parseDateString` 已有序列号分支（45320→2024-01-29 已验证）。

### H2 — 原子去重硬兜底
`lib/db/index.ts`（两个既有 dedup 索引之后）：
```sql
delete from brain_notifications where id not in (
  select min(id) from brain_notifications group by user_id, dedup_key, date(created_at / 1000, 'unixepoch'));
create unique index if not exists brain_notifications_user_dedup_day_idx
  on brain_notifications (user_id, dedup_key, date(created_at / 1000, 'unixepoch'));
```
唯一索引为硬兜底：并发第二次 INSERT 抛 UNIQUE，被 `insertBrainNotification` 既有 try/catch 吞掉返回 null（不产生重复行）。

### H3 — snooze 真正生效
`lib/brain-notification.ts`：`enqueueNotification` dedup 查询改为 `or(gte(createdAt, now-WINDOW), gte(snoozedUntil, now))`。

### H4 — 明天提醒不误去重
`lib/brain-proactive-brief.ts`：`listRecentBriefKeys` 增加 `ne(brainProactiveState.actionStatus, "tomorrow")`（drizzle 0.45 为 `ne`，非 `neq`）。

### H5 — 完成联动
`lib/brain-db.ts` 新增 `markBrainReminderItemDone`；`lib/brain-notification.ts` `applyNotificationAction` 的 done/ignore 分支调用 `maybeCompleteReminderItem`（refType==="reminder_item" 时标记 item 完成，断开通知循环）。

### H6 — 轻量 note 投影
`lib/brain-db.ts` 新增 `BrainNoteMeta` 类型 + `listBrainNoteMetas`（排除 content/struct/embedding/codeContent）；`lib/brain-reminder.ts` 的 `getDecayedNotes`/`computeDecayedNotes` 改调轻量投影，轮询不再全量载全文+AI JSON。

### H10/H11 — 业务级质量信号
