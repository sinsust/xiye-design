### 批次④ 可访问性

**新增 `lib/use-dialog-a11y.ts`**（供条件渲染浮层复用）：

- ESC 关闭（document 级，不依赖焦点是否在浮层内）
- Tab / Shift+Tab 焦点陷阱，焦点不跑到浮层背后
- 打开时焦点移入、关闭时归还触发元素
- `useId()` 生成稳定 `titleId` 供 `aria-labelledby`
- 泛型 `<T extends HTMLElement>` 兼容 `aside` / `div`
- `onClose` 用 ref 稳定 —— 调用方内联箭头函数不会导致 effect 重跑、焦点被反复抢

**接入与补齐**：

| 位置 | 处置 |
|---|---|
| workflow 4 抽屉（journey / screen-map / screen-spec / concept-brief） | `{...dialogProps}`（`role=dialog` `aria-modal` `aria-labelledby` `tabIndex=-1`）+ 标题 `id={titleId}` |
| `concept-brief-panel` 关闭按钮 | 补 `aria-label="关闭"` |
| builder 变体抽屉（**常驻挂载**，transform 隐藏） | 不用焦点陷阱；改 `role=dialog aria-modal={false} aria-hidden={!drawerOpen} inert` + `aria-labelledby` |
| 输入框 3 处（builder-checkpoints / decision-suggestion-card / project-identity） | 补 `aria-label` |
| collab-stage 3 个 icon-only 按钮 | 补 `aria-label`；动态文案提取为 `continueWithAssumptionsLabel`，`title` 与 `aria-label` 同源 |
