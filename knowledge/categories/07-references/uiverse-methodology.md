# Uiverse 组件展示交互方法论（reference）

## 内容
Uiverse.io 是当前最大的开源 UI 组件库（社区构建，数千个组件、100% 免费商用）。它展示/交互组件的**方法论**值得借鉴：

1. **画廊式实时预览**：所有组件平铺成可交互画廊，每条在列表里**直接实时跑起来**（动画、hover、切换效果当场可见），而非静态缩略图。
2. **暗/亮主题一键切换**：预览区可反复衬托组件在不同主题下的表现。
3. **详情页承载"完整代码 + 使用说明"**：点开组件不止看到效果，还有可读说明与完整源码。
4. **多格式一键复制**：核心亮点——同一组件可 `Copy as HTML / CSS / Tailwind / React / Figma`，把「看→复制→接入」压成一个动作。
5. **品类 + 搜索 + 标签导航**：按钮/卡片/加载器/输入/开关/表单等分类，配合搜索快速到达。
6. **社区贡献 + 宽松版权**：任何人可贡献组件，可商用。

## 适用场景
- **该用**：设计组件展示区、组件库站点、骨架工作台的组件预览面——都该朝"能实时看效果 + 一键复制多格式代码 + 可切换主题预览"靠。
- **不要用 / 注意**：它偏"HTML/CSS 微组件"级，复杂业务组件（数据表格/富文本）不在此列；复制代码要关注其实际样式耦合。

## 何时看
- 改造组件预览/挑选体验、让"看→复制→接入"更顺时；与我们骨架组件/视觉契约联动。
