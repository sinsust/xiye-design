# magicui（repository）

## 作用
面向**设计工程师**的 UI 库：**150+ 动画组件与动效**，构建在 React + TypeScript + Tailwind + Motion 上，复制粘贴式使用，量大且可直接出效果。

## 适用场景
- **该用**：营销页、产品 Landing、SaaS 官网需要光效/渐变/动画网格/射线等"高级感"组件时。
- **不要用 / 注意**：全站都用会显得花哨且偏重；与视觉契约的克制原则衔接，挑关键组件用。
- **替代**：`reactbits`（更偏创意背景）、`aceternity`（落地页区块）、`motion`（底层）。

## 技术栈 / 要求
- React + Tailwind + Motion（framer）。
