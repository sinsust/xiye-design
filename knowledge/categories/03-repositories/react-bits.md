# reactbits（repository）

## 作用
收集 **110+ 动画化、交互式的 React 组件**，集中于创意 UI、背景动画、视觉展示组件，适合"复制粘贴即用"地增强落地页观感。

## 适用场景
- **该用**：个人页/营销页/创意页需要背景动画、粒子、卡片动效等直接可用组件时。
- **不要用 / 注意**：正式 SaaS 后台的严肃交互用 shadcn 更合适；引用前核对包体积与许可证。
- **替代**：`magicui`（同类的动画组件库）、`motion`（底层动画引擎）、`shadcn/ui`（通用组件）。

## 技术栈 / 要求
- React + Tailwind（部分用 Motion）。
