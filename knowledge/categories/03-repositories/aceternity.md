# aceternity-ui（repository）

## 作用
面向 **Landing / 落地页** 的组件库：提供 Hero、Features、**Bento Grids**、Parallax Blocks、Shaders 等区块与模板，快速拼出有"设计感"的营销页。

## 适用场景
- **该用**：SaaS 官网、营销落地页、需要现成区块快速组版时。
- **不要用 / 注意**：部分区块动效较重；与极简/克制风格可能不搭；以官网可用组件为准（个别非开源需自行评估）。
- **替代**：`reactbits`、`magicui`、`shadcn/ui`（基础底座）。

## 技术栈 / 要求
- React + Tailwind + Motion。
