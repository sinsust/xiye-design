# Uiverse（repository）

## 作用
**社区驱动的开源 UI 元素库**（the largest library of open-source UI）：上千个社区组件，涵盖按钮、卡片、加载器、输入、开关、表单、动效等；**多个组件可一键复制**为 HTML / CSS / Tailwind / React，且 **100% 免费个人与商用**。

## 适用场景
- **该用**：需要快速取现成"微组件"当参考/直接接入时；作为我们骨架组件 / 视觉契约的**组件来源候选**，生成时可引用其 HTML/CSS/React 形态。
- **不要用 / 注意**：复杂业务组件不在此列；样式常自成一派，复制进需对齐本项目视觉 token（`DESIGN_SPEC`）；以官网最新为准核对许可证。
- **替代**：`shadcn/ui`（Radix 组件体系）、`magicui`/`react-bits`（动效组件）、`aceternity`（落地页区块）。

## 技术栈 / 要求
- HTML/CSS 为主，部分提供 Tailwind/React/Figma 形态。

## 拿来即用 vs 仅供参考
- 微组件可直接复制作为生成/实现参考；
- 其"按品类 + 实时预览 + 多格式复制"的展示方式可借鉴到我们工作台。
