# 现有项目重设计（skill）

## 作用
对**已有项目**做设计升级：先审计当前设计、识别出通用 AI 模式（slop），再**在不破坏功能**的前提下把视觉提升到高端标准。

## 适用场景
- **该用**：改造存量站点/接手有提升空间的既有产品时。
- **不要用**：全新从零设计时，从 `design-taste-frontend` / `design-kungfu` 起步。
- **替代**：`design-kungfu`、`high-end-visual-design`（标准本身）。

## 用法 / 接入
1. 复制到项目 `skills/`。
2. 审计 → 识别 slop → 逐区块提升，保持功能可用。

## 依赖
- 面向任意 Web 框架。
