# 极简编辑风 UI（skill）

## 作用
**极简编辑风**：暖色单色调、靠排版对比建立层级、扁平 bento 网格、柔和粉彩配色；**无渐变、无重阴影**，观感安静高级。

## 适用场景
- **该用**：内容型 / 展示型 / bento 面板 / 偏好克制安静界面的项目。
- **不要用**：需要强烈视觉张力或硬核工业感时，改 `industrial-brutalist-ui`。
- **替代**：`ui-ux-pro-max`（任选风格）；`high-end-visual-design`（贵感路线）。

## 用法 / 接入
1. 复制到项目 `skills/`。
2. 按其极简规则产出 UI。

## 依赖
- 面向任意 Web 框架。
