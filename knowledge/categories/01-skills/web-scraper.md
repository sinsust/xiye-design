# 网页内容抓取（skill）

## 作用
抓取指定 **URL** 的网页内容，提取其中的**文本、标题、链接、图片**，供数据采集与后续分析使用。

## 适用场景
- **该用**：需要把某个网页内容结构化摘取下来（数据采集、竞品/资料调研、语料整理）。
- **不要用 / 注意**：遵守目标站 robots/版权；需要动态渲染的页面可能要配合无头浏览器。
- **替代**：`1688-sourcing-inquiry`（采购询盘场景）；浏览器自动化逐站操作。

## 用法 / 接入
1. 复制到项目 `skills/`。
2. 给 URL → 提取文本/标题/链接/图片 → 供下游分析。

## 依赖
- 通用（任意栈，需网络访问）。
