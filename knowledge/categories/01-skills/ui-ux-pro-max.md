# UI/UX 设计智能库（skill）

## 作用
一个**本地可搜索**的 UI/UX 智能数据库：内含 **84 种风格 / 192 组配色 / 74 组字体搭配 / 22 个技术栈** 的参考，供设计选型时快速锚定方向（可仅用作参考数据，不强制出代码）。

## 适用场景
- **该用**：不确定走哪种风格/配色/字体，想先查一通本地数据库做决策依据时；与本底座的 `VISUAL_STYLES` 联动参考。
- **不要用**：已有明确风格并要完整落地系统时，用 `design-kungfu` 生成完整方案。
- **替代**：`design-kungfu`、`stitch-design-taste`（成体系规范）。

## 用法 / 接入
1. 复制到项目 `skills/`。
2. 按需求检索风格/配色/字体/技术栈 → 锚定设计方向。

## 依赖
- 面向任意 Web 框架；可作为只读参考库食用。
